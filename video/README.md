# KRIYA product video

A ~2-minute product video made with [Remotion](https://www.remotion.dev): React motion graphics, rendered to MP4.

- **Voiceover:** Microsoft Edge neural TTS, Indian English (`en-IN-NeerjaExpressiveNeural`), generated by `tts.py` from `narration.json`. It also writes sentence timings to `src/voice.json`, which drive the subtitles and the on-screen animation beats.
- **Music:** a royalty-free ambient pad, synthesized with ffmpeg (`build/music.mjs`).
- **Product shots:** screenshots of the live Monad app (https://kriya-monad.vercel.app), captured at 2× in `public/shots/`.

```bash
npm install
pip install edge-tts
npm run voice                        # regenerate the voiceover (or: python tts.py en-IN-PrabhatNeural for a male voice)
npm run studio                       # live preview / edit
npm run render                       # → out/KRIYA-product-video.mp4
```

Scenes live in `src/Scenes.tsx`; scene length follows the voice, so editing `narration.json` and running `npm run voice` re-times the whole video.
